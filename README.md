**Página Web de Mueblería Jota**

Presentamos un sitio web desarrollado para la empresa *Mueblería Jota*, diseñada con una estética moderna, minimalista y una paleta de colores neutra que refleja la identidad de la marca. 
El sitio permite a los usuarios explorar el catálogo de productos, conocer la historia de la empresa, gestionar compras en línea, registrarse para acceder a promociones exclusivas y ponerse en contacto de forma directa.

 **Funcionalidades Principales**
 
* **Catálogo e Interacción:** Exploración interactiva de productos con un buscador dinámico de muebles.
* **Proceso de Compra:** Flujo simulado de carrito de compras y adquisición de productos.
* **Registro de Usuarios:** Sistema para suscribirse y acceder a promociones y novedades.
* **Atención y Sugerencias:** Formularios para resolver dudas, enviar comentarios o ponerse en contacto directo con la empresa.
* **Historia y Marca:** Sección dedicada a transmitir los valores y la trayectoria de Mueblería Jota.
